# 飞书表格与网站的约定

三张表的字段可以各不相同，在飞书里增删改字段后重新同步即可，不用改代码。网站按下面的规则理解每张表：

| 内容           | 规则                                                                                                                                   |
| -------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| 字段顺序       | 取这张表**第一个视图**里的字段顺序（`+field-list` 每次返回的顺序都不同，视图里的顺序是稳定的）。视图里隐藏的字段仍然会导出，排在最后。 |
| 名称           | 第一个视图里的**第一个字段**，必须是文本字段，不能为空。字段改名不受影响。                                                             |
| 描述           | 字段名叫「描述」的文本字段，没有就留空。显示在名称下面。                                                                               |
| 筛选项和表格列 | 这张表里**所有单选和多选字段**，每个字段一个下拉、一列表格。同一字段里同名的选项合并成一个。                                           |
| 详情           | 名称和描述在标题下面，**其余字段全部列出**，按飞书里的字段顺序；没有值的显示「—」；整段是网址或超链接的值显示成可点击的链接。          |
| 附件           | 同步时下载到 `public/files/`（按文件令牌分目录），详情里显示成可下载的文件名和大小，单个文件上限 10 MB。                               |
| 不支持的类型   | 只支持文本、单选、多选和附件。人员、关联、数字、日期等字段会被跳过，同步时以「警告」列出。                                             |

限制：单选和多选字段的名称不能是 `type`、`q`、`view`、`item`（它们是网址参数）；选项里不能有英文逗号。

> **所有字段都会公开导出，附件也会作为静态文件公开**，任何人知道网址都能下载。不要往任何字段或附件里放密钥、令牌或内部备注。暂时不想公开的内容，不要放在表里。

## 网址参数

`?type=skill|mcp`（缺省是 `guide`，也就是 AGENTS.md）、`&<字段名>=选项1,选项2`（筛选）、`&q=关键词`、`&view=grid`、`&item=<记录 ID>`。

## 解析飞书数据的小提示

本机的 `jq` 不认中文作为裸标识符。取中文字段要写成 `.["备注"]`，不能写 `.备注`，也不能在 `{}` 里用中文当键；复杂处理改用 `python3`。

## 页面代码里对应的位置

- 同步脚本：`scripts/sync.ts`（读取飞书、下载附件）、`scripts/normalize.ts`（规整一张表，测试在 `normalize.test.ts`）。
- 筛选和网址状态：`src/lib/filter.ts`（测试在 `filter.test.ts`）。
