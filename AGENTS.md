### Operations runbooks
`references/` holds this project's operations runbooks. Do not work from memory: read the matching runbook before acting. Read `references/ops-basics.md` first (project facts, hard rules, status check), then the runbook for the task:

| Task | Read |
| --- | --- |
| Feishu data changed, sync and publish the site | `references/sync-and-publish.md` |
| Change page code, styles or copy | `references/code-change.md` |
| Feishu authorization expired (`need_user_authorization`, `token_missing`) | `references/feishu-auth.md` |
| Cloudflare build not triggered, build failed, live site not updated | `references/deploy-troubleshooting.md` |
| Roll back a deployment | `references/rollback.md` |
| Change site path or domain, add a fourth Feishu table | `references/advanced-changes.md` |
| How Feishu fields map to the site, URL parameters | `references/feishu-conventions.md` |
| An error message you do not recognize | `references/error-lookup.md` |
| First-time setup, rebuild Cloudflare | `references/first-time-setup.md` |

Rules that always apply (full list in `references/ops-basics.md`):
- The site is public. Everything exported from Feishu, including attachments, is published. Never publish secrets, tokens, passwords or local paths.
- Pushing to `main` deploys to production. Only push when the user asks; otherwise commit and stop. Never force-push.
- `src/data/toolchain.json` and `public/files/` are generated by `vp run sync`. Never edit them by hand.
- Feishu authorization has to be completed by the user in a browser.
- When a runbook is wrong or outdated, fix it in the same change as the code.

## Web development toolchain

Use `vp` for web development. Vite+ is the unified toolchain for the web behind the `vp` CLI — one tool combining Vite, Rolldown, Vitest, tsdown, Oxlint, Oxfmt, and Vite Task, plus runtime and package-manager management.

First, read https://viteplus.dev/llms-full.txt to learn Vite+'s commands and configuration.

Then open a new terminal and run `vp help`. To scaffold a new project run `vp create`; to move an existing Vite project onto Vite+ run `vp migrate`.

Day-to-day commands: `vp install` (dependencies), `vp dev` (dev server), `vp check` (format + lint + type-check), `vp test` (tests), and `vp build` (production build).
